{% tr "How to connect Google, PageSpeed and Bing (free)" %}

1 · Google Search Console

  1. {% tr "Open console.cloud.google.com with the Google account that owns Search Console, and create a project (for example technting-cms-seo)." %}
  2. {% tr "Go to APIs & Services → Library, search for “Google Search Console API” and press Enable. Do the same for “PageSpeed Insights API”." %}
  3. {% tr "Go to APIs & Services → Credentials → Create credentials → Service account. Give it a name (for example technting-cms-seo) and press Done. It needs no roles." %}
  4. {% tr "Open the new service account → Keys → Add key → Create new key → JSON. A .json file downloads. Keep it private." %}
  5. {% tr "Copy the service account's email (it ends with iam.gserviceaccount.com)." %}{% if client_email %} {{ client_email }}{% endif %}
  6. {% tr "Open search.google.com/search-console → Settings → Users and permissions → Add user. Paste the email and choose Full permission." %}
  7. {% tr "Here in the dashboard: Plugins → Technting SEO → choose the .json file under “Google service account key”, turn the plugin on and save." %}
  8. {% tr "Come back to this page and press Refresh now. Search data appears within a minute; Google's figures run about 3 days behind." %}

2 · PageSpeed Insights

  1. {% tr "In the same Google Cloud project: APIs & Services → Credentials → Create credentials → API key." %}
  2. {% tr "Press Edit API key → API restrictions → Restrict key, choose PageSpeed Insights API and press Save." %}
  3. {% tr "Copy the key and paste it in Plugins → Technting SEO → PageSpeed Insights API key. Pages are checked once a month, two at a time." %}

3 · Bing ({% tr "optional" %})

  1. {% tr "Open bing.com/webmasters and sign in. Choose Import from Google Search Console to add the site in one step." %}
  2. {% tr "Open Settings (the gear) → API access → API Key → Generate, and copy the key." %}
  3. {% tr "Paste it in Plugins → Technting SEO → Bing Webmaster Tools API key and save." %}
